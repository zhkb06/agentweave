## 操作步骤

1. 剪映首页 → 新建草稿；右侧「草稿参数」把 **比例 16:9、分辨率 1080P、帧率 30** 设好（点「修改」）。
2. 素材面板「导入」→ 分三次导入：`docs/视频素材/`（4 段 mp4）、`docs/视频素材/卡片/`（3 张 png）、`docs/视频素材/幻灯片/`（14 张 png）。
3. 按上表顺序把素材拖到主轨道（剪映会自动首尾相接），先不管时长，全部铺好一遍。
4. 逐段修时长：
   - 图片：拖片段右边缘，拉到表格的建议时长（拖的时候上方会显示时间码）。
   - 视频：拖**右边缘**裁掉多余尾部；需要裁头时拖**左边缘**；表格里给了入点/出点。
5. 旁白（8 段）：
   - 打开 `旁白文本-8段.txt`，按 S1…S8 顺序复制。
   - 时间线左侧工具条选「文本」→ 把「默认文本」拖到时间线最上层，放到该镜头起点。
   - 右侧面板点「文本」，把内容换成该段旁白 → 点「朗读」→ 选「解说小帅」→ 勾选「朗读跟随文本更新」→ 点「开始朗读」，等 5–15 秒生成音频。
   - 生成后把该文本片段删掉（音频会保留在音轨上），避免大字盖住画面。
   - 8 段都这样处理；最后检查旁白是否首尾相接、没有空档或重叠。
6. 字幕：工具条选「字幕」→「智能识别」→「开始识别」，等 20–40 秒生成字幕轨（自动按停顿切行）。
7. 导出：右上「导出」→ 标题填 `AgentWeave_演示视频_织流AgentWeave` → 分辨率 原始(1080P)、帧率 30、格式 MP4 → 导出。
8. 导出后把文件路径发我，我做最后的成片校验（时长/分辨率/有无黑屏/字幕是否压住关键信息）。
