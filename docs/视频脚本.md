# 织流 AgentWeave —— 演示视频分镜脚本（4 分钟版）

> 规格：1920×1080（录制建议 1280×800 窗口放大字号），25 fps，H.264，含硬字幕
> 时长：4 分 00 秒（满足 3–5 分钟要求，留 10 秒容错）
> 讲述：男/女声均可，语速约 240 字/分钟；全片旁白约 960 字

## 四、字幕与旁白规范

1. **硬字幕**：底部居中，黑底 60% 透明，白字 28–32pt，单行不超过 22 字，最多两行。
2. **术语统一**：首次出现写「PDCA 自循环（计划-执行-检查-处理）」，之后用「自循环」。
3. **数字必带单位与来源**：如「最大偏差 34.4%，容差 15%」；基准数字须与 `data/benchmark.json` 一致；本片所有数字均已实测（见该文件与方案书 9.3）。
4. **不念代码**：代码段只做画面展示，旁白讲意图。
5. **禁用词**：「革命性」「颠覆」「全球首创」等无法证实的表述一律不用。

## 五、备用方案（录制故障预案）

| 风险 | 预案 |
|---|---|
| 现场运行超时或卡顿 | 预先录好一段完整运行，剪辑时用录屏替换实时段，画面标注「实录」 |
| 浏览器字体过小 | 提前把浏览器缩放调至 110%，并在系统设置里把窗口分辨率降到 1280×800 |
| 声音嘈杂 | 使用耳麦单独录音，后期对齐；旁白语速比平时慢 10% |
| 演示数据首轮没失败 | 确认使用 `examples/datasets/air_quality.csv` 与演示工作流默认参数；不要手动改容差 |
| 文件找不到 | 提前在资源管理器固定 `data/runs/` 与 `docs/` 目录，录制时用地址栏直达 |
