# 生产化检查表 · 织流 AgentWeave

> 用途：上线前逐项打勾；评审/客户安全问卷可直接引用本表。

## 一、安全

| 项 | 状态 | 实现/说明 |
|---|---|---|
| 写接口鉴权 | ✅ | 可选 Bearer Token（`config.server.auth_token` 或 `AGENTWEAVE_AUTH_TOKEN`）；仅保护 POST，health 豁免；`tests/test_production.py::AuthTests` |
| 密钥管理 | ✅ | LLM Key 只从环境变量/本机配置读取，接口返回打码；日志不打印 Key |
| 路径穿越 | ✅ | 静态文件与产物下载均 `resolve()` + `relative_to()` 校验（`app.py` `serve_static`/`_resolve_artifact_path`） |
| 请求体上限 | ✅ | 2MB（`MAX_BODY_BYTES`），超出 413 |
| 安全响应头 | ✅ | `X-Content-Type-Options`、`X-Frame-Options: DENY`、`Referrer-Policy`、`Permissions-Policy` |
| 限流 | ✅ | 每 IP 令牌桶：运行类 10/min、其它写 60/min（可配置）；429 统一错误体 |
| 并发保护 | ✅ | `runtime.max_concurrent_runs`，超出 429 `TOO_MANY_RUNS` |
| 命令执行隔离 | ✅ | `python_exec` AST 白名单 + 子进程 + 超时 + 输出截断（`tools/builtin.py`） |
| 工具权限白名单 | ✅ | Agent 只能调用 `spec.tools` 声明的工具，未授权调用被拒绝并回注模型 |
| HTTPS | ⚠️ | 应用层不终止 TLS，由 Nginx/Caddy/云负载均衡提供；见部署指南第五节 |
| 登录/多租户 | ❌ | 单团队部署；公网只读展示建议前置 OAuth2 Proxy |
| CSRF | ⚠️ | 无 Cookie 会话，写接口靠 Bearer Token；若在前面加 Cookie 登录需补 CSRF |

## 二、可靠性与数据

| 项 | 状态 | 实现/说明 |
|---|---|---|
| 运行历史持久化 | ✅ | 每次运行写 `data/runs/<id>/summary.json`；重启后 `list_runs/get_run` 自动回落磁盘 |
| 磁盘保留策略 | ✅ | `runtime.run_history_keep`（默认 50），启动时清理最旧目录 |
| 运行取消 | ✅ | `POST /api/runs/{id}/cancel`，事件总线广播 `run.cancel_requested` |
| 运行超时/步数上限 | ✅ | `max_steps`、节点 `timeout_s`、自循环 `max_iterations` |
| 优雅退出 | ✅ | Ctrl+C/SIGTERM 关闭平台事件循环与 HTTP 服务 |
| 崩溃恢复 | ⚠️ | 进程重启后历史可查询；运行中的 run 会标记为失败，需重新触发 |
| 数据备份 | ⚠️ | `config/` + `data/runs/` + `data/logs/` 目录级备份；无内置定时备份 |
| 分布式执行 | ❌ | 单机单进程；多 worker 需替换 `RunStore`/`Scheduler` 后端 |
