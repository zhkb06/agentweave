## 六、已知边界（评审可能追问，主动说明）

1. **单机演示**：调度器与执行器同进程，未做分布式 worker 池；并发上限为节点 4 / Agent 2（可配置）。
2. **合成数据**：演示数据集为固定种子合成，真值隐藏；真实数据接入只需替换 `examples/datasets/` 与工作流 `scan` 节点路径。
3. **默认 Mock LLM**：离线演示使用确定性 Mock，保证评委断网可复现；接入真实模型只需在「模型设置」填写 OpenAI 兼容端点与 Key。
4. **验证层以规则为主**：五层中的 `llm_judge` 为可选检查器，默认演示关闭，避免引入非确定性。
5. **未做百级节点压测**：已完成 5 次端到端基准（单机 0.7–1.1 s/次，约 84 条事件），规模上限未做系统性压力测试。
